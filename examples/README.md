# Examples

One night, hand-written to match what the offline simulator produces
(`docs/operations.md`); nothing here comes from a real vault.

| File | What |
|---|---|
| `env` | `/etc/librarian/env` as the installer writes it |
| `daily-before.md` | the daily note at 03:00, two lines to file |
| `daily-after.md` | the same note after the run: `To file` cleared, `## Filed` written by the wrapper from git |
| `pr-body.md` | the filing PR's description: the model's `## Notes` per realm, the diffstat |
| `output.denials` | what a probing model gets: `[guard]` is `lib/guard`, `[rule]` is Claude Code's deny list |
